# Publix In-Stock Command Center

Publix version of the retailer command-center framework used for Target and H-E-B.

## Included
- Publix-branded responsive desktop/mobile shell
- Store dashboard
- Unavailable/OOS watch
- Case additions workflow with local persistence
- Regional dashboard
- Division / region / delivery / store filters
- CSV store export
- Vercel-ready static deployment

## Data adapter
The current repository includes starter/demo store and product data in `data.js` so the interface is functional immediately.

Replace the starter inventory function/data with the live Publix source once the desired store/product availability source is identified.
